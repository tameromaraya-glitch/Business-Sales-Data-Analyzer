# Business Sales Data Analyzer

## Project Overview
A Python tool that analyzes business sales data from Excel files.

## Features
- Reads Excel files
- Checks required columns
- Calculates total profit and profit margins
- Classifies products by profit margin
- Identifies the most profitable product
- Generates an executive summary
- Exports a formatted Excel report with a profit chart

## Technologies
- Python
- Pandas
- OpenPyXL
- Microsoft Excel

## How It Works
1. Upload an Excel file.
2. The tool reads and validates the data.
3. It calculates profits and profit margins.
4. It classifies products based on margin thresholds.
5. It exports the results to an Excel report.

## Note
This is a learning portfolio project tested on sample business data.
